## 3. 新增功能与修复

- 机器狗 77 个、人形 138 个具名模块直接登记在场景树中，子网格通过父节点追溯部件，未另存一份部件状态。
- 四腿分别建立髋 → 膝 → 踝/足端链。人形腰关节带动胸部、颈部、头部及双臂，骨盆和双腿保持独立；前臂下建立腕 → 掌 → 五指链，每手各指具有 3/3/3/3/2 个独立关节。
- 工作台悬停显示部件中文名称与稳定路径编号，离开模型后清除提示。
- 用薄保护壳替换躯干实心块体，内部能源、控制和传感器均具有独立安装位置与可见支撑；雷达、主板、视觉和无线模块补齐实际支架。
- 根据足部实体厚度将人形机身站立基准从 1.035 m 改为 1.06 m，保留 IK 连杆长度；测试检查整个足端包围盒没有穿入地面。
- 实际截图确认散热鳍片此前被侧壳遮挡，外移后可见；新的人形颈/头结构在 360px 靠近名称，将默认焦点从 0.91 m 提高至 1.14 m，最新生产截图已复核。
- 螺栓使用局部 InstancedMesh，卸载时显式释放实例缓冲，并沿现有场景清理几何、材质和上下文。

已核对安装版本 Three.js r187 的源码和官方 [InstancedMesh](https://github.com/mrdoob/three.js/blob/r187/docs/pages/InstancedMesh.html)、[ExtrudeGeometry](https://github.com/mrdoob/three.js/blob/r187/docs/pages/ExtrudeGeometry.html)、[RoundedBoxGeometry](https://github.com/mrdoob/three.js/blob/r187/docs/pages/RoundedBoxGeometry.html) 文档。原始核对记录在 `library-docs-results.json`。

## 5. 未解决的问题与边界

- 阶段二没有已知阻塞问题；真实手机、Safari/Firefox、低端 GPU 和长时间压力测试尚未执行。
- 两台机器人为项目原创程序化概念模型，没有外部 GLB/贴图/字体、模型地址、账号或 API 依赖；第三方库保留各自许可证。
- 独立关节节点已建立，但当前动作系统仍驱动原有 12 个轴。完整腰/颈/腕/机械手动作、关节滑块、动作集与遥测扩展属于阶段三，尚未实现。
- 传感器是具名机械实体，未实现点云扫描、环境识别、真实压力/惯性测量或无线设备通信。所有动作与数据仍为 SIMULATION。
- 内部去壳和手指旋转通过复用实际模型的独立验收夹具完成；不是产品的透视、爆炸拆解或机械手控制入口。完整实验室、感知、AI、任务、HUD/对比与最终验收仍待后续阶段。
- 当前目录无 Git 元数据，本次未提交、推送或远端部署。4173/5174 为本机生产预览/开发服务。
