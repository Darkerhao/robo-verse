## 3. 新增功能与实现取舍

### 雷达、点云与识别

- 雷达速度 0.1–2 圈/s，距离 3–14m；HIGH/MEDIUM/LOW 每圈分别使用 180/120/72 个方位和九个俯仰角。
- 只记录实体表面交点。实时缓冲最多保留 6000 条最近观测，历史保留最近五个完整扫描圈；支持清除、显示开关、类别颜色、距离热力、障碍轮廓和局部聚焦。
- 回看暂停扫描与正在执行的路线，返回实时继续扫描，路线由用户显式继续；改变距离/密度或移动箱体清除旧采样。
- 双目中心位置、机身/腰/颈姿态、水平 110° 与垂直 80° 视场、距离和遮挡共同产生识别状态。地面锚点来自摄像头向下射线与实际地面的交点。
- 已识别对象显示类别、演示置信度、距离、方位、状态。未识别对象明确显示被遮挡/视场外/量程外；识别框只显示已识别目标。
- 两列标注连接真实目标投影，避免短屏文字覆盖；识别模式隐藏重复悬停提示。

### 路线与控制闭环

- 0.25m 网格、八邻域 A*，连续路段同样检查碰撞；四足/人形占地安全半径为 1.05/0.70m，覆盖实际最高步行速度的机械包围盒。
- 网格用于搜索，终点保留实际坐标。坐标输入允许任意小数，与地面拾取产生的非网格坐标一致。
- 路线支持规划、开始、暂停、继续、停止、重置与到达。位置、关节步态、速度、距离/方位、扫描和进度由同一快照驱动。
- 动态箱体调整同一实体并重新规划，保持当前位置；与机器人重叠的位置明确拒绝，无法到达的终点停止执行并说明原因。
- 每台机器人的世界坐标属于 `RobotState.worldPosition`，感知直接引用；急停后换机再返回也保持锁定位姿。
- 导航使用连续步态和实际速度，不受工作台单次动作时长/播放倍率截断；工作台原设置保持不变，退出导航后继续生效。
- 全局暂停冻结感知/运动，急停停止导航、扫描、速度与功率。释放急停即刻提供确认站姿及对应传感器位置。

使用现有运动学、Three.js 几何和一个仿真时钟完成本阶段，无物理引擎、外部模型下载、视觉 API 或第二套运动实现。
