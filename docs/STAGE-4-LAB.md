## 3. 新增功能与修复

### 结构拆解

| 步骤 | 机器狗 | 人形机器人 |
| --- | --- | --- |
| 1 | 外部保护壳 | 头部外壳 |
| 2 | 上部外壳 | 视觉感知模块 |
| 3 | 电池系统 | 胸部外壳 |
| 4 | 主控制器 | 主控制器 |
| 5 | 传感器模块 | 电池系统 |
| 6 | 主体框架 | 双臂模块 |
| 7 | 四肢机械结构 | 灵巧手 |
| 8 | 关节电机 | 腰部关节 |
| 9 | 减速器 | 双腿模块 |
| 10 | 足端结构 | 关节执行器 |

各模块沿明确的机器人坐标轴分离。位移转换回实际父级坐标，俯仰、转向或关节运动后仍保持拆解轴向。子部件随父级移动，并在自身步骤增加局部分离；不重挂机械节点，不覆盖关节旋转或机身仿真位置。

进度为 0–10，对应 0–100%，每步采用平滑补间。开始、暂停、继续与反向恢复只改变同一进度，重复进度不会累计位移。完整拆解或恢复各约 11 秒，暂停恢复后继续仍保持反向装配。恢复原状显示被隐藏的部件并保留观察设置；重置实验室清除全部展示设置，保留当前动作。

### 部件与观察

- 鼠标悬停高亮并显示稳定编号；点击锁定部件、打开详情并聚焦。目录按拆解步骤组织，支持中英文/编号搜索、空状态、独立隐藏/显示及全部显示。
- 详情提供中英文名称、稳定路径编号、结构说明、层级/步骤、独立自由度、关联关节角度与限位，以及明确标注的系统电机温度和驱动功率。详情自动进入面板可视区域。
- 外壳透明时内部实体保持不透明，并排除透明外壳的拾取。隐藏部件及其后代不再被 Raycaster 命中；选择隐藏模块内的部件会恢复其祖先显示。
- 支持感知模块、关节、电池与控制器高亮。选择/悬停/透明使用缓存材质变体，不修改共用原材质；透明外壳关闭深度写入和阴影投射，取消后恢复原材质。
- 骨骼连线、关节节点、末端、局部 X/Y/Z 坐标轴从实际机械节点生成，随运动与拆解更新。选中关联关节后显示橙色角度范围/正向旋转和绿色末端轨迹；原关节滑块、IK、动作与回放均可使用。
- 聚焦只统计可见机械实体，不把辅助线和隐藏零件纳入包围盒。相机保持侧高位，跟随选中节点位移；鼠标操作后尊重用户视角。重置或拖动进度后立即选择也使用当前展示位置。

### 本轮发现并修复

- r187 Raycaster 不检查 `visible`：改为筛选实际可见机械实体，排除透明外壳，避免隐藏零件与外壳挡住内部拾取。
- `Box3.expandByObject(mesh)` 不更新父级矩阵：查询前更新模型世界矩阵，解决初次/改变姿态后的旧包围盒。
- 重置→立即选择曾使用前一帧拆解位置：真实诊断中人形控制器旧 target 为 `(0.883, 2.075, 0)`，当前装配 target 为 `(0.083, 1.435, 0)`。聚焦前直接应用当前展示状态，修复竞态。
- 关闭坐标轴后提前返回曾保留重置前轨迹：回归先复现 16 个旧轨迹点，清理选择/轨迹移到提前返回之前，重置后立即为 0。没有新增另一套重置状态。
- 1366×768 底部重置区有约 6px 超出首屏：实验室独立高度下限调整为 420px，并解除共用视口的 460px 下限，最新生产两机短屏复核通过。
- 移除旧实验室占位分支、未使用的分类英文与父级元数据；复用原运动面板并省去重复机型信息。

已核对当前安装的 Three.js 0.187.0 源码及同版本官方 [Raycaster](https://github.com/mrdoob/three.js/blob/r187/docs/pages/Raycaster.html)、[Material](https://github.com/mrdoob/three.js/blob/r187/docs/pages/Material.html)、[Box3](https://github.com/mrdoob/three.js/blob/r187/docs/pages/Box3.html)、[AxesHelper](https://github.com/mrdoob/three.js/blob/r187/docs/pages/AxesHelper.html) 文档。保留现有 GSAP 相机补间，结构使用原渲染循环推进，没有新增动画时钟。

## 5. 未解决的问题与边界

- 本阶段功能没有已知阻塞问题。本机 HIGH 短测约 25 FPS，60 FPS 性能目标尚未达到，保留为第九阶段性能优化与最终验收事项。
- 拆解为原创概念模型的轴向结构演示，不代表工业 BOM、真实装配工艺、力学约束或硬件拆卸过程。原模型与动作使用运动学仿真，无真实设备连接。
- 部件温度/功率读取统一系统参数，不提供单部件独立硬件温度、机械负载或传感器测量信号；感知模块当前为真实几何实体，扫描/识别/距离在阶段五实现。
- 真实手机、Safari/Firefox、低端 GPU 和长期压力尚未专项验收。结构状态保存在当前会话，刷新重开；场景重载可保留当前实验室展示状态。
- 模型继续由项目原创程序化生成，无外部模型、贴图、账号或 API 依赖。第三方库保留各自许可证。
- 第四阶段代码与文档按用户后续要求在 main 分支本地提交，未推送或远端部署；运行入口为本机开发/生产预览。
