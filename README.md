# NEXT ROBOTICS · 下一代智能机器人数字孪生体验中心

在浏览器中探索四足机器狗与人形机器人的三维交互平台。项目严格按 [ROLE.md](ROLE.md) 和 [MASTER_PROMPT.md](MASTER_PROMPT.md) 的九阶段规范增量开发，已完成前七阶段：视觉框架、机械模型、动作系统、全息实验室、AI 感知、自然语言控制和任务中心，并保留实时遥测和日志。第八阶段完整 HUD 与第九阶段最终优化尚待实施。

所有运动与参数均标记为 **SIMULATION**：使用本地运动学模拟，不连接真实设备，也不代表商业机器人性能。

## 运行

需要 Node.js **22.12+**（建议当前 LTS）、npm，以及支持 WebGL 2 的现代浏览器。首次安装需要联网；运行时的模型、材质、图表和图标均随工程提供，无 CDN、账号或 API Key 依赖。

```sh
npm ci
npm run dev
```

打开 <http://127.0.0.1:5177/>。开发服务仅监听本机，按当前 `vite.config.ts` 固定使用 5177；端口被占用时会报错。

```sh
npm test             # 机械层级、运动学、感知/避障、仿真和遥测生命周期回归
npm run typecheck    # Vue / TypeScript 类型检查
npm run build        # 类型检查 + 生产构建，输出 dist/
npm run preview      # 预览生产构建，默认 http://127.0.0.1:4173/
```

生产部署需要将 `dist/` 放在站点根目录，并将非静态资源路由回退到 `index.html`，以支持 `/robots`、`/telemetry` 等地址刷新。`vite preview` 用于本地检查构建结果。

顶部 AI PERCEPTION、AI CONTROL 和 MISSIONS 分别进入感知、自然语言和任务中心。PERFORMANCE 按阶段八开发并明确禁用；已有基础遥测仍可从实验工具栏访问。

AI 控制默认使用不联网的本地规则解析器，输入必须命中动作白名单。支持“让机器狗向前走1秒，然后向左转45度”这类顺序指令；机器狗移动和巡检会复用感知训练场的同一避障路线，人形动作调用现有运动学控制。未知动作、错误机型、越权参数和不安全代理地址会被拒绝。安全代理协议为 `POST` JSON `{ operation: "parse", model, text, robotType }`，返回 `{ commands: RobotInstruction[] }`；连接测试使用 `{ operation: "test", model }` 返回 `{ ok: true }`，代理服务负责保管上游 API Key。

方向移动按朝向前进或后退，速度与时长决定最大距离；使用同一场景碰撞体和占地间距，在实体或场地边界前提前停止，无安全空间时明确失败。巡检继续使用 A* 绕障到达终点。画质、视图与聚焦设置不取消当前 AI 指令；有效手动控制才接管，拒绝的输入保留原任务。

## 任务中心

`/missions` 提供智能工厂、现代仓库、科技实验室、室外道路、楼梯训练场、障碍物训练场，场景均为原创本地程序化环境，使用独立灯光色与任务对象。

- 工业巡检：移动到设备、识别、记录预设温升异常、返回起点。
- 安防巡逻：沿道路检测警戒区人员、记录异常、巡查设备并返航。
- 复杂地形：四足逐足适应0.08/0.16m台阶，越过0.07m低障碍并通过通道，展示平衡。
- 搜救：绕废墟搜索、识别并标记人员、返回安全区。
- 物品抓取/仓库搬运：识别箱体、接近、弯腰张手、确认双手接触、抬起、沿安全路线搬运、对准支架放置；对象与掌心同步。
- 人机交互：人员接近、识别、挥手、转向并指向实验台、恢复待机。

每个任务提供开始、暂停、继续、停止、重置、时间/位置/动作/进度、步骤、最多100条事件与完成结果。进度按实际路线距离或动作阶段计算；识别、接触和放置校验未通过时会失败，不产生成功结果。任务/全局暂停冻结相关位姿和对象；停止保留持物姿态，重置恢复该任务初始位置与对象；急停锁必须先手动解除。离开任务中心停止任务，再进入重新准备。场景/任务切换在执行中禁用，需停止或重置后选择。

准备状态可在任务页调整移动速度；含位移的任务速度为0时明确拒绝并可原地调速恢复，无位移的人机交互允许零速度。暂停或急停期间进入任务会显示尚未就绪，继续仿真/解除急停后重置准备。开始自动聚焦并跟随机器人，也可全场总览、拖动观察、点击对象聚焦或折叠面板。任务以同一仿真时钟执行，导航复用感知中心的A*与安全路段执行器。识别、异常、抓握、地形和结果均为SIMULATION：几何视场/遮挡识别、掌心约束与足端IK，不是视觉模型推理、刚体动力学或真实设备验证。

## 操作与状态

- 感知中心提供正常、雷达、点云、AI 识别、路径规划五种视图，切换视图保持机器人位置和路线。切换机型重新在起点训练；已经急停的设备保持锁定世界位置。
- 雷达从原模型镜窗位置进行水平 360° 多线束扫描，速度 0.1–2 圈/s、距离 3–14m；点云只记录最近实体表面交点，支持光束/点云/轮廓开关、类别颜色、距离热力图和清除。画质同步控制每圈 72/120/180 个方位采样，调整距离或密度会重新采样。
- 实时点云最多保留 6000 条最近表面观测，扫描历史保留最近五个完整扫描圈。回看历史暂停扫描和正在执行的路线，返回实时继续扫描；路线需要显式继续。历史只保存在本次会话中。
- 摄像头根据实际机械安装位置、朝向、水平 110°/垂直 80° 视场、距离与遮挡生成演示识别结果。已识别目标显示类别、置信度、距离、方位和状态；被遮挡、视场外、量程外的对象不显示识别框。两列标注连接真实目标投影，避免短屏文字覆盖。
- 路径视图可点击空闲地面，或通过快速终点/XZ 坐标规划。A* 使用 0.25m 网格及机器人保守占地半径（四足 1.05m、人形 0.70m），避开实体和粉红禁行区；开始/暂停/继续/停止/重置均实际驱动同一运动状态。移动速度为 0 时停止位移和迈步，到达后返回站姿。
- 自动路线使用连续步态并按实际速度推进，不受工作台单次播放时长或动画倍率限制；工作台原有单次/倍率设置保持不变，退出导航后继续生效。
- 「移动箱体」调整同一训练实体的位置并重新规划，保留当前位置；与机器人重叠的位置明确拒绝。全局暂停冻结感知和运动，急停停止路线、扫描与驱动；解除急停恢复确认站姿，重新开始路线需要显式操作。
- 选择环境对象可查看详情与局部放大，「聚焦机器人」跟随当前机器人的移动，「全场总览」恢复训练场视角。模型、训练对象与扫描资源均在本地生成，感知中心加载后可断网继续操作。

- 首页左键拖动旋转视角、滚轮缩放、右键平移；悬停显示机器人名称，点击按模型包围范围聚焦，双击进入对应机器人工作台。聚焦时首页文案隐藏，点击空白处或恢复视角可返回大厅构图。
- 工作台提供透视、正视、侧视、顶视及缩放按钮；全屏时保留三维操作，减少动态效果偏好会关闭首页视差与相机补间。
- 工作台悬停机械部件显示中文名称和稳定部件路径编号，离开模型后清除提示。在全息实验室点击模型或选择目录部件，可锁定详情并聚焦；点击空白或关闭按钮取消选择。详情提供中英文名称、编号、结构说明、层级/拆解步骤、自由度、关联关节角度与限位，以及明确标记的系统模拟参数。
- 实验室按两机型的十步机械顺序轴向分离，支持开始、暂停、继续、0–100% 手动进度和反向恢复；完整拆解/恢复各约 11 秒。恢复装配保留观察开关，并显示被隐藏的部件；「重置实验室」清除全部结构和观察设置，保留当前机器人动作。
- 外壳透明时内部实体保持不透明，鼠标可穿过外壳拾取内部部件。选择内部电池、控制器或框架会自动开启透视；支持感知模块、关节、电池与控制器分类高亮。材质切换不修改共用原材质。
- 机械骨骼、关节节点、局部 X/Y/Z 坐标轴从真实模型节点生成，随运动和拆解更新。选择关节后显示橙色角度范围与旋转方向、绿色末端轨迹；「调节此关节」直接打开已有受限关节控制。聚焦跟随节点位移，鼠标操作相机后保留用户视角。
- 实验室使用同一仿真状态，原动作、关节、IK 与回放均可在「动作实验」中操作。全局暂停与当前机型急停冻结结构播放；切换机型或退出实验室清除展示状态，保留各机型原有运动状态。
- 选择其他机型会回到该机型的默认透视视角，保留两台机器人的各自状态。
- 控制面板提供「动作 / 关节 / 末端 IK」三种入口。动作支持 0.25–2× 倍率、循环/单次播放与平滑停止；静态姿态持续保持，单次动态动作结束后回站姿。步态速度只影响移动动作，0 m/s 停止迈步。
- 「关节」按机械部位选择机器狗 12 轴或人形 45 轴，滑块显示目标、当前角度与范围。手指每个指节均可独立控制；调节单轴不修改其他关节目标。
- 「末端 IK」支持四足各足端 X/Y 平面定位、人形双臂 X/Y/Z 掌心定位。坐标相对所选髋/肩关节，+X 向前、+Y 向上、+Z 向右，单位 m。超出工作空间会保留原目标并提示；腿部/足端独立实验抬高机身留出活动空间，手臂与机械手保持当前高度，点击「恢复站姿」返回地面支撑姿态。
- 「开始记录」捕获当前机器人的实际关节、机身和朝向，最长 20 秒，支持结束、回放与清除。两机记录独立，暂停冻结记录/回放，急停结束记录并锁住当前姿态。记录保存在本次会话内，重置会清除记录。
- **暂停仿真**冻结两台机器人的仿真时间、动作和遥测，允许继续观察相机；**继续仿真**从原状态运行。
- **紧急停止**立即将当前机器人速度与驱动功率归零并锁定姿态；**解除急停**在普通工作台返回完整站姿；任务中保留锁定姿态与持物关系，重置任务后恢复初始场景。另一台机器人不受单机急停影响。
- **重置场景**将两台机器人恢复初始站姿、朝向、电量并重新计时，清空遥测和关节记录，保留运行日志和已有急停锁定。
- 画质设置提供 HIGH / MEDIUM / LOW：分别限制最高 2× / 1.5× / 1× 像素比，低画质关闭阴影；支持显示或隐藏地面网格。调整画质会保留用户的缩放视角。
- 页面退到后台时不推进仿真、不渲染新帧；返回后继续运行，不补算离开期间的时间。
- 状态仅保存在当前页面内存中，刷新页面会重新开始；导出 CSV 可保存遥测。

## 工程结构与数据流

技术栈：Vue 3、TypeScript、Vite、Pinia、Vue Router、Three.js、ECharts、GSAP、Less。精确安装版本由 `package-lock.json` 锁定。

```text
src/
├── components/             3D 视口、控制面板、图表、对话框与 SVG 图标
├── config/robots.ts        机型演示参数与动作配置
├── config/joints.ts        共用机械尺寸、关节范围、模型节点与末端目录
├── config/lab.ts           两机拆解顺序、轴向位移、部件说明与展示状态类型
├── config/perception.ts    训练实体/禁行区、传感器安装尺寸、占地包络与感知类型
├── config/missions.ts      六场景实体、七任务步骤、地形表面
├── types/mission.ts        任务命令、状态、事件与结果
├── simulation/MissionEngine.ts    共用时钟中的任务编排/完成条件
├── simulation/missionKinematics.ts 双臂掌心约束、抓放轨迹与地形IK
├── three/EnvironmentModel.ts      感知/任务共用环境实体建模
├── three/MissionScene.ts          任务场景、持物、路径与识别标注
├── services/SimulationAdapter.ts  唯一仿真状态源，处理命令与推进模拟
├── simulation/kinematics.ts       全动作姿态、支撑/摆动轨迹、FK/IK 与足端约束过渡
├── simulation/perception.ts       表面射线、摄像头视场/遮挡、扫描历史与导航执行
├── simulation/pathPlanning.ts     占地膨胀、八邻域 A* 与安全路段简化
├── stores/simulation.ts    Pinia 订阅、设备选择、遥测窗口与日志
├── stores/lab.ts           唯一结构展示状态：进度、播放、选择、隐藏与观察开关
├── three/RobotModel.ts     原创程序化机械结构与关节显示
├── three/RobotParts.ts     共用机械几何/材质工具、稳定部件名称及拾取溯源
├── three/RobotLab.ts       原模型装配偏移、材质变体、骨骼/坐标轴/轨迹与实体包围盒
├── three/PerceptionScene.ts 环境实体、点云缓冲、扫描平面、识别标注与路线显示

├── types/robot.ts          设备、命令、快照、遥测与适配器协议
```

操作通过 Pinia 发送 `RobotCommand` 给 `SimulationAdapter`。适配器以 10 Hz 推进状态，统一求解腿、腰、颈、肩、肘、腕与手指，处理目标、过渡和记录回放，再发布完整快照。3D 模型、控制面板和遥测读取同一关节数组及目录；图表以约 2 Hz 采样，每台机器人保存最多 120 条数据。动作切换和渲染插值先混合机身与足端位置，再解腿部 IK，使支撑脚保持接触高度；独立关节实验按角度插值，保持单轴隔离。

`RobotAdapter` 定义 `connect / disconnect / send / subscribe` 接口和 `simulation / ros2 / mqtt` 模式类型。本阶段只有 `SimulationAdapter` 实现。后续设备适配器应在此边界接入真实设备确认的状态，并在状态层处理异步命令及连接错误；不得把模拟快照当作真实连接成功。

大厅、机器人工作台、全息实验室、感知中心和任务中心使用同一个 `createScene` 实现。单机场景和双机大厅共用机械模型及仿真状态，机型专属路由与控制面板保持同步。实验室/感知中心切换机型复用当前场景的模型；模块切换清理旧场景，避免重复渲染循环。

感知与导航由同一个 `SimulationAdapter.tick` 以 10 Hz 推进。每台机器人的世界坐标存于 `RobotState.worldPosition`，感知位置直接引用该坐标；原 `RobotPose.position` 仍表示局部机身姿态。传感器与模型共用安装尺寸，环境实体、射线碰撞体、识别框和规划障碍物共用同一配置。导航以当前运动速度推进实际路段，再求解机械姿态并更新感知，渲染不生成独立运动或识别状态。

实验室目录从原机械场景树生成，`stores/lab.ts` 只管理展示状态。现有渲染循环推进结构进度，先由 `RobotModel.update` 应用仿真姿态，再由 `RobotLab.update` 叠加轴向分离与可视化；不另开动画循环、不改关节旋转、不重挂机械层级。相机聚焦前应用当前展示状态，防止重置/拖动进度后的旧位置竞态。拾取排除隐藏实体与透明外壳，聚焦只统计可见机械实体，不包含骨骼辅助线。

场景卸载时断开 ResizeObserver，取消相机 GSAP 动画，释放 OrbitControls、几何、材质、螺栓/骨骼实例缓冲、点云/光束缓冲、辅助几何、材质变体、阴影、环境贴图及 WebGL 上下文，并删除感知文字与 SVG 引线。遥测图表卸载时释放 ECharts 实例。应用卸载时停止适配器定时器和订阅。WebGL 中断时显示重新加载入口，重载保留实验室展示状态及感知的模式、位置、点云、参数与路线。相机调试数据仅在开发模式生成。

## 模型来源与边界

- 两台机器人均由项目内 `RobotModel.ts` 原创程序化生成，包括薄保护外壳、承载框架/脊柱、独立电池与控制板、IMU、散热、传感器支架、电机/减速器、连杆、足端和人形灵巧手；未下载第三方机器人模型、贴图或字体。
- 机器狗包含双目/深度摄像头、雷达、超声波传感器和无线通信模块。人形包含双目/深度摄像头、头部雷达、语音模块及足底压力传感器实体。感知中心已提供几何雷达和视场/遮挡识别，传感器实体及结果仍为模拟，未接入真实压力或设备反馈。
- 部件直接登记在 Three.js 场景树中，当前机器狗 77 个、人形 138 个具名模块；外壳与内部系统分开挂载。每条腿独立使用髋 → 膝 → 踝/足端链；人形增加腰 → 胸/颈/头/双臂链，以及肘 → 腕 → 掌 → 五指链，各手指有 3/3/3/3/2 个独立旋转节点。
- 房间环境光由 Three.js 自带 `RoomEnvironment` 程序化生成；第三方依赖保留各自许可证。
- RV K1 / RV H1 是概念机型，不代表特定厂商产品；质量、速度上限、电量、温度和功耗为明确标注的演示参数。
- 机器人工作台保持原地步态演示，感知训练场提供实际三维平移与基于几何的路线避障。没有刚体动力学、足底力反馈或硬件控制；转向、平衡与晃动仍为受限运动学，不能据此推断真实物理稳定性。
- 机器狗驱动 12 轴；人形驱动 45 轴（腿部 6、腰/颈 3、双臂/腕 8、双手指节 28）。各轴进入同一动作状态和遥测；这是概念模型的可控轴数，不代表商业硬件自由度。关节实验提供角度限制，不提供全身自碰撞求解。
- 拆解顺序与位移是原创概念模型的结构演示，保留装配层级，不是工业装配工艺或真实机械拆卸仿真。部件温度/功率是统一系统参数，不提供独立硬件负载或传感器测量信号。
- 雷达点云与摄像头识别来自已知训练场几何，置信度是距离/视角/遮挡产生的演示值，不是机器学习推理或 SLAM。任务中心已提供阶梯运动学与对象抓放任务；AI 助手默认使用本地规则。ROS 2 / MQTT 尚未实现，本地模式无需 AI API 或 Key。真实外部 AI 接入需通过安全后端代理。
